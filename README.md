# CalcAndConverter

CalcAndConverter is a simple Android app that combines a basic calculator with a handy unit converter.

## Features

- **Calculator**: Perform basic arithmetic operations (addition, subtraction, multiplication, division, percentages, etc.) with a clean and intuitive interface.
- **Unit Converter**: Instantly convert between:
  - Inches and Centimeters
  - Pounds and Kilograms
  - Fahrenheit and Celsius
  - Miles and Kilometres
  - Litres and Millilitres

## How to Use

1. **Calculator**
   - Enter numbers and operations using the on-screen buttons.
   - Press `=` to see the result.
   - Use `C` to clear, and `del` to backspace.
   - Use `%` for percentage calculations.

2. **Unit Converter**
   - Enter a value in the input field.
   - Select the conversion type from the dropdown menu.
   - Tap `Convert` to see the result below.

## Technologies Used
- Kotlin
- Android SDK
- [exp4j](https://www.objecthunter.net/exp4j/) for expression evaluation

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/skodinger/CalcAndConverter.git
   ```
2. Open the project in Android Studio.
3. Build and run on your device or emulator.
